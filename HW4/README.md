# HW4 : todo 앱에 API 더하기
## 더한 것
- 설명 칸(note)을 API 로도 주고받게 했습니다.
- GET /api/todos/?done=true 로 완료한 것만 골라 받게 했습니다.
## 실행하는 법
pip install -r requirements.txt
flask --debug run
화면 http://127.0.0.1:5000/
문서 http://127.0.0.1:5000/api/docs
