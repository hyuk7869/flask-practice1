## 단계 ③ 답
- linear regression 은 열을 더하는 직선밖에 못 그린다. 총액은 수량 × 단가, 곱이라서 직선으로 근사하다 0.862 에 그쳤다.
- qp(수량 × 단가)를 열로 넣으면 총액 = qp 한 줄이 되어 1.0 이 된다.

## 단계 ⑤ 결정과 이유
- max_depth = 8
- cross-validation 평균이 depth 8 은 0.992, depth 12 는 0.995 로 0.003 차이다. 점수가 거의 같으니 잎이 적은(250 대 781) 단순한 쪽을 골랐다.
- training 1.000 과 test 0.994 의 차이가 작은 것은 총액 = 수량 × 단가라는 규칙이 실제로 있어서다.

## 단계 ⑦ 답
- linear + qp 를 올렸다.
- 수량 40, 단가 200,000 에서 linear + qp 는 8,000,000 으로 실제 곱과 같고, tree (depth 8) 는 7,362,301 로 모자란다. tree 는 훈련에서 본 값을 계단으로 나눠 답해서 곱을 그대로 내지 못한다.
